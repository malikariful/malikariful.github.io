# Ariful Malik Academic Website

This is a lightweight single-page academic website inspired by the simplicity of Rayhanur Rahman's site, but organized around Ariful Malik's own academic profile.

## Files
- `index.html` — complete website (styles are embedded)
- `assets/Ariful_Malik_CV.docx` — current CV copy

## Add your photo
1. Put a headshot at `assets/profile.jpg`.
2. In `index.html`, replace:
   `<div class="portrait">MA</div>`
   with:
   `<div class="portrait"><img src="assets/profile.jpg" alt="Md Ariful Islam Malik"></div>`

## Publish with GitHub Pages
1. Create a GitHub repository, for example `malikariful.github.io`.
2. Upload `index.html` and the `assets` folder to the repository root.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` / root.
4. Your website will then be available at the GitHub Pages address.

## Optional improvements
- Replace the DOCX CV with a PDF and update the CV links.
- Add a News section for awards, conference presentations, and new publications.
- Add project pages for your dissertation studies.
